## 13. 中间件降级有效 + Redis 无业务真源

**走查**：`redis.enabled=false` + 重启（执行文档许可的降级演练方式；另以"键不落库"互证）。**T19 收尾复验（中间件全 Docker 化后）**：直接 `docker stop weiguang-redis` 即真实触发降级——登录成功、订单列表 code=0、日志现降级 WARN 行；`docker start` + 重启后端后探测恢复、限流键复现于容器。
**证据**：

```
重启日志：命中降级行（"redis.enabled=false，限流与热点缓存全部走本地降级实现"）
降级期间：登录成功、订单列表 code=0（主线仍走通）
键不落库互证：降级期间连续登录后，Redis 中 rate:login:* 键数量=0（限流走了本地计数）
键抽查：Redis 现存键仅 browse:dedup:*（浏览去重）与 rate:*（限流）、TTL 有效 → 无订单状态/账本/聊天消息等业务真源
恢复：redis.enabled=true + 重启 → 探测日志"Redis 探测成功"，限流键与 TTL 复现
```

**结论：通过**。
